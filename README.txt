TO THE MOON & BACK — ANNIVERSARY WEBSITE

FILES
- index.html : page structure and content
- style.css  : colors, layout, responsive design, animations
- script.js  : names/date configuration, counter, music, letter modal, quiz, surprise

HOW TO CUSTOMIZE
1. Open script.js.
2. Edit CONFIG.yourName and CONFIG.partnerName.
3. Edit CONFIG.anniversaryDate using YYYY-MM-DD format.
4. Edit the five quiz questions and answer options in CONFIG.quiz.
5. Edit the love-letter text in index.html.
6. Replace placeholder content and adjust colors in style.css as you like.

MUSIC
- Create a folder named "assets" beside index.html.
- Put a legally usable MP3 file in it and name it "music.mp3".
- The music button works after the file is added. Browsers require a user click before audio starts.

RUN LOCALLY
- Open index.html in a browser.
- For best testing, use a local server such as VS Code Live Server.

PUBLISH ONLINE
- Upload index.html, style.css, script.js, and the assets folder (if used) to a static host such as GitHub Pages or Netlify.
- Keep the three main files in the same directory.

NOTES
- Names, date, quiz options, and letter are placeholders.
- The site does not use a database or collect form submissions.
- This is a static site; anyone with the public link may view it.
